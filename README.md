# Educação Kids

Projeto estático em HTML, CSS e JavaScript, organizado para hospedagem no GitHub Pages, Vercel ou outro serviço de site estático.

## Estrutura

- `index.html` — página principal
- `oferta-especial.html` — condição especial
- `css/styles.css` — estilos
- `js/` — scripts do site
- `assets/images/` — imagens
- `assets/videos/` — vídeos
- `vercel.json` — configuração de hospedagem

Mantenha a estrutura de pastas ao publicar.
